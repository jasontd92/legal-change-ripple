## D. Update rules for scenario files
- **Edit scenarios in place.** Keep IDs stable. For a removed scenario,
  replace its body with `REMOVED: <reason>`. New scenarios take the next free
  ID in that file.
- **Update paths, section numbers, expectations, Verify and Realism lines**
  affected by the changes above. Resolve VERIFY items the changes settle.
- **Re-check every scenario that touches a now-expired document** (use
  `python3 corpus/status_at.py 2026-10-01` or the manifest's
  `status_at_as_of`) and decide per §C5.
- **Add scenarios only where a change creates new eval value.** Examples:
  - the Sunpoint renewal letters as V5 / legal-status / M1 cases
  - GPC-INV-26-1911 vs 1912
  - the CA terms pair as version resolution
  - the IL 2022–2024 needs-review band
  - Castellano §12
- **Remove Gaps entries the changes resolve,** and add any new ones.
- **Append a `## Revision 2026-09-29` section** at the end of the file
  (before `STATUS: complete`) listing each scenario changed, added or
  removed, one line each.
